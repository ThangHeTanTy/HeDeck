HeDeck Agent — chạy trên máy tính Windows, nhận lệnh từ điện thoại
====================================================================

1. Nháy đúp HeDeckAgent.exe
   - Windows SmartScreen cảnh báo "Windows protected your PC":
     bấm More info -> Run anyway. File chưa mua chứng chỉ ký nên Windows
     chưa nhận ra, không phải virus.
   - Windows Firewall hỏi: chọn cho phép ở Private networks (mạng riêng).

2. Cửa sổ agent hiện địa chỉ IP và mã ghép cặp 6 số. Mở app HeDeck trên
   điện thoại (cùng Wi-Fi), chọn máy này và nhập mã.
   Hết hạn mã thì nhấn Enter trong cửa sổ agent để lấy mã mới.

3. Giữ cửa sổ agent mở trong lúc dùng (thu nhỏ được).

Tuỳ chọn
--------
- TU_CHAY_CUNG_WINDOWS.bat : tự mở agent mỗi khi đăng nhập Windows.
                             Chạy lại lần nữa để gỡ bỏ.
- CAI_BAT_MAY_TU_XA.bat    : cấu hình card mạng để bật máy từ điện thoại
                             (Wake-on-LAN). Cần cắm dây LAN và bật trong BIOS,
                             xem docs/BAT_MAY_TU_XA.md trên GitHub.

Cập nhật
--------
Agent tự hỏi GitHub khi mở và mỗi 12 giờ. Có bản mới thì cửa sổ agent báo
kèm ghi chú thay đổi; gõ C rồi Enter để cập nhật, agent tự mở lại.
Không gõ C thì agent không bao giờ tự cài gì cả.

Dữ liệu (điện thoại đã ghép cặp, danh mục app) lưu ở %USERPROFILE%\.hedeck,
không mất khi cập nhật.
